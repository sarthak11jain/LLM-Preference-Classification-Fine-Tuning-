# CPU demo report

These files are generated from the synthetic data in `data/demo/`:

- `metrics.json` — uniform-prior baseline log loss;
- `calibration.json` — demo log loss, Brier score, and ECE;
- `reliability.svg` — demo reliability diagram;
- `probability_histograms.svg` — per-class probability distribution;
- `submission.csv` — competition-format sample output.

They are package smoke-test artifacts, not Gemma-2 evaluation results.
