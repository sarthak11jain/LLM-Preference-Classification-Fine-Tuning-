# Security policy

Do not commit Kaggle credentials, API tokens, raw competition data, private
dataset identifiers, model weights, adapter checkpoints, or generated files
that contain sensitive metadata.

If sensitive information is discovered, remove it from the working tree and
rotate the credential immediately. For a repository issue involving a possible
secret, use a private security channel rather than posting the value publicly.

This project does not require credentials to import or test its public Python
package.
